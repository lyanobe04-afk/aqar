How Unit Availability Works

Availability logic evaluates 4 sovereign parameters in real time before publishing to booking channels:

1
Setup Status Whether a unit has the required configuration data, layout plans, and rental specifications.
2
Occupancy Status Whether a unit is actively occupied by a registered tenant, vacant, or unassigned.
3
Maintenance Status Whether the unit is clear, blocked by work orders, or awaiting formal inspection sign-off.
4
Booking Availability Synthesized eligibility determining if the unit can accept manager-approved booking requests.
lock_clock

Phase 1 Protocol: All eligible rental bookings require property manager review and manual verification. Instant booking and automated payment collections are not enabled.
